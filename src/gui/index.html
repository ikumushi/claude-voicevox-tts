VOICEVOX 読み上げ設定

変更すると settings.json の env だけを書き換えます。Hook の登録や他のツールの設定には触りません。 保存は Claude Code の再起動なしで、次のターンから効きます。

試聴

保存する前に、いまの画面の値で1回だけ鳴らして確かめられます。

鳴らす前に、前の読み上げが残っていれば止めます。エンジンが起動していない場合は 自動で起動するため、初回は少し待つことがあります。

元に戻す

保存するたびに、直前の内容を settings.json.voicevox-backup に取っています。1つ前の状態に戻せます。
